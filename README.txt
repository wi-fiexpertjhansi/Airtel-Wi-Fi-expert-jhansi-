FREE PUBLISHING WITH GITHUB PAGES:
1. Sign in to https://github.com/ and create a new public repository named wifi-expert-jhansi.
2. Upload index.html to the repository's main/root folder.
3. Open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch 'main' and folder '/ (root)', then Save.
6. After publishing, GitHub will show your free website address.
